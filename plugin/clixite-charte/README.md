# Plugin Claude · charte Clixite

Ce plugin fait appliquer la charte graphique Clixite par Claude, dans Claude (application et Cowork) comme dans Claude Code.

## Ce qu'il contient

| Élément | Rôle |
|---|---|
| Compétence `charte-clixite` | Appliquer le design : modèles PowerPoint, Word et Excel, kit HTML, logos, jetons, règles complètes, DESIGN.md pour les agents. |
| Compétence `rediger-clixite` | Écrire dans la voix de la marque, en français, néerlandais et anglais, avec le lexique et les faits établis. |
| Compétence `verifier-charte-clixite` | Contrôler un contenu (texte, HTML, CSS, Word, PowerPoint, Excel) avec un score sur 100. |

## Exemples de demandes

- « Fais-moi une présentation Clixite de 8 slides pour proposer un Fractional CPO à une PME. »
- « Rédige un post LinkedIn sur la mise en production de la policy achats, en français et en anglais. »
- « Vérifie cette offre avant que je l'envoie. »
- « Crée une page d'atterrissage aux couleurs de Clixite pour l'offre DORA et NIS2. »
- « Prépare le tableau de suivi des actions pour le client, au modèle Clixite. »

## Installation

- Claude (application, Cowork) : ouvrir le fichier `clixite-charte.plugin` dans la conversation et accepter.
- Claude Code : `/plugin install` depuis le dossier décompressé, ou ajouter le dossier comme marketplace locale.
